How to Publish on GitHub Pages

Pulse Chat • Made by Ahmad Bin Shifa

Step 1: Create a GitHub Repository

1. Go to github.com/new

2. Repository name: pulse-chat

3. Select Public and click Create repository.

Step 2: Upload index.html

1. Click "uploading an existing file" or create a new file named index.html.

2. Copy & Paste all this code into index.html and click Commit changes.

Step 3: Enable GitHub Pages

1. Go to repository Settings → Pages tab.

2. Under Branch, select main (or master) and click Save.

Your live site URL will be ready at: https://yourusername.github.io/pulse-chat/
